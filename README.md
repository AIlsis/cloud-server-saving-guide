## 一、轻量应用服务器 vs CVM

| 对比项 | 轻量应用服务器 | CVM 云服务器 |
|---|---|---|
| 上手难度 | 低，面板化运维 | 高，需要自己配环境 |
| 带宽 | 固定峰值带宽，便宜大碗 | 按固定带宽/流量计费，弹性 |
| 内网互联 | 不支持 | 支持，可组私有网络 |
| 适用场景 | 建站、学习、轻量业务 | 生产集群、企业应用 |
| 价格 | 约为同配置 CVM 的 4-6 折 | 原价 |
| 运维工具 | 内置宝塔/一键镜像 | 需自行安装 |

**一句话**：个人和轻量业务选轻量；上生产、组集群选 CVM。轻量不适合跑高并发生产业务，也不支持自定义 VPC。

## 三、省钱三原则

### 1. 能买长周期就不买短周期

云厂商对新用户的首购优惠集中在包年包月：

- 新用户专享价通常只有**首年**享受
- 续费恢复原价，差价可能 3-5 倍
- 如果业务确定要长期跑，首单直接买 3 年（部分活动支持 5 年），锁定低价

> 注意：确认活动机型是否支持「续费同价」。支持的话，每年续费也是这个价，最划算。

### 2. 踩准大促节点

腾讯云全年几个固定大促：

- 3 月开学季
- 6 月 618
- 8 月周年庆
- 11 月双 11
- 云产品福利专区（长期滚动，新客专享价+代金券）

大促期间同配置往往比日常价低 40%-70%。不急就等节点，急用就先去福利专区捡漏。

### 3. 代金券 + 新用户身份用满

- 新用户注册后先领券再下单，结算页记得勾选可用代金券
- 一个实名身份的新用户优惠通常只能用一次，别浪费在低配上——直接一步到位买目标配置
- 企业用户走企业认证，部分活动企业价更低且返佣产品更多

## 四、下单前自查清单

- [ ] 确认是**新用户专享价**（老用户很多活动看不到）
- [ ] 确认时长：首单尽量买 1-3 年，别按月续
- [ ] 确认带宽和月流量，超了按量付费很贵
- [ ] 确认系统镜像，Linux 省资源，Windows 需要更高配置且占授权
- [ ] 确认地域：目标用户在哪选就近地域，延迟低还便宜（部分地域有折扣）
- [ ] 确认是否需要备案：国内节点需要域名备案，不想备案选中国香港节点

## FAQ

**Q：轻量服务器能升级配置吗？**
A：可以。在控制台直接升配，数据保留，但升配按余期补差价，价格不如新购划算。

**Q：老用户还有优惠吗？**
A：部分活动开放「老用户专属区」，但力度远小于新客。最稳的是等大促或蹲福利专区。

**Q：腾讯云和阿里云/华为云怎么选？**
A：同档配置比价即可，谁便宜买谁。腾讯云轻量在低价带宽上给得大方，适合个人站长；阿里云生态全，适合企业。

**Q：通过推广链接买会不会更贵？**
A：不会。价格与官网完全一致，返佣由腾讯云从推广者侧出，不从你的订单扣。

**Q：买了服务器不会用怎么办？**
A：轻量自带一键部署镜像（宝塔、WordPress 等），零基础也能跑起来。
